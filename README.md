# IncumbINT

The relationships behind federal contracting.

IncumbINT reads the public record of federal procurement (SAM.gov, USAspending, FPDS, solicitation documents, budget books, protests) and maps the relationships in it: incumbents, recompetes, vehicles, offices, suppliers.
